# NEXORA ONE — Expérience intelligente (brief produit, sections 1 à 8)

> Brief dicté par le propriétaire du produit, conservé tel quel. Il s'arrête à la section 8 ;
> l'implémentation est décrite dans [nexora-one-experience-intelligente-implementation.md](nexora-one-experience-intelligente-implementation.md).

---

Tu es un Principal Product Designer, UX/UI Architect, Senior Frontend Engineer et Software Architect spécialisé dans les applications SaaS professionnelles, ERP, POS, FinTech et systèmes intelligents de gestion.

Je veux concevoir et développer NEXORA ONE.

NEXORA ONE n'est PAS un simple logiciel de gestion, ni un simple ERP, ni un simple POS.

C'est une plateforme intelligente de gestion d'entreprise nouvelle génération.

L'objectif est de créer une expérience qui donne à l'utilisateur l'impression d'utiliser le système d'exploitation intelligent de son entreprise.

==================================================
2. VISION FUTURISTE
==================================================

Imagine que NEXORA ONE soit le "Operating System" d'une entreprise.

Au lieu de simplement afficher :

Ventes
Stock
Finance
RH
Clients

NEXORA ONE doit comprendre :

- ce qui se passe
- ce qui vient de se passer
- ce qui risque de se produire
- ce qui nécessite une attention
- ce qui pourrait être amélioré
- quelle action pourrait être entreprise

Le système doit donc évoluer de :

DATA → INFORMATION → INSIGHT → RECOMMENDATION → ACTION

Exemple :

Au lieu de :

"Stock : 37 unités"

NEXORA ONE doit pouvoir afficher :

------------------------------------------------
OPPORTUNITÉ DÉTECTÉE

Eau minérale 1.5L

Stock actuel
37 unités

Ventes moyennes
12 unités / jour

Tendance
+18 %

Couverture
3.1 jours

Délai fournisseur
7 jours

RISQUE DE RUPTURE ÉLEVÉ

NEXORA recommande :
Commander 120 unités

Pourquoi ?
• demande en hausse
• stock insuffisant
• délai fournisseur supérieur à la couverture actuelle

[VOIR L'ANALYSE]
[MODIFIER]
[COMMANDER]
[IGNORER]
------------------------------------------------

Le système ne doit donc pas seulement montrer les données.

Il doit aider l'utilisateur à comprendre son entreprise.

==================================================
8. IA CONVERSATIONNELLE
==================================================

Créer un assistant intelligent intégré à NEXORA ONE.

Nom conceptuel :

NEXORA AI

L'utilisateur peut demander :

"Pourquoi mes bénéfices ont diminué ?"

"Quels produits dois-je commander ?"

"Quels produits se vendent le mieux ?"

"Pourquoi mon stock diminue ?"

"Quels clients ont des paiements en retard ?"

"Montre-moi les dépenses qui ont augmenté."

L'IA doit répondre avec :

- données
- graphiques
- explications
- sources
- recommandations

Exemple :

USER :

Pourquoi mes bénéfices ont diminué ?

NEXORA AI :

Votre bénéfice a diminué de 8.4 %.

Principales causes :

1. hausse du coût fournisseur : +12 %
2. baisse des ventes : -4 %
3. augmentation des dépenses opérationnelles : +7 %

Impact estimé :

- 245 000 HTG
