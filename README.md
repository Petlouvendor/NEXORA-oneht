# Nexora One

Plateforme universelle de gestion commerciale, POS, financière et comptable multi-entreprises.

> **Nom du produit : « Nexora One »** (marque affichée). Les identifiants techniques restent
> `Nexora.*` (namespaces .NET), `nexora` (schéma PostgreSQL), `nexora_app` (rôle DB), `nxk_`
> (préfixe de clé d'API) — inchangés, invisibles pour l'utilisateur.

# 1. Base de données
export PGPASSWORD=...
cd database/scripts && ./rebuild.sh && cd ../..
psql -h localhost -U postgres -d nexora -f database/scripts/smoke_test.sql
psql -h localhost -U postgres -d nexora -f database/seeds/demo_abc_group.sql

# 2. Backend

# 3. Frontend
